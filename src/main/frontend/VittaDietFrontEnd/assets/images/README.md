# Imagens

Coloque aqui as fotos reais em formato `.webp` (ex.: `salada.webp`).

Na landing (`index.html`), cada `.photo-tile` do banner hoje tem uma ilustração
SVG provisória. Para trocar por uma foto, substitua o `<svg>` por:

```html
<img src="/assets/images/salada.webp" alt="Bowl de salada colorida" width="400" height="600" loading="lazy">
```
